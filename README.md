
# 🛒 E-Commerce App

Приложение для интернет-магазина книг, созданное с использованием React, Vite и TypeScript.

## 📦 Используемые технологии

- ⚛️ **React** — интерфейс приложения
- ⚡ **Vite** — сборщик и дев-сервер
- 🟨 **TypeScript** — типизация
- 🧪 **Jest** — модульное тестирование
- 🎨 **Prettier** — автоформатирование кода
- 🔍 **ESLint** — линтинг JavaScript/TypeScript кода
- 💅 **Stylelint** — линтинг CSS/SCSS
- 🪝 **Husky** — Git-хуки для автопроверок

## 🚀 Установка и запуск проекта

### 1. Клонирование репозитория

git clone <https://github.com/your-username/e-commerce-app.git>
cd e-commerce-app

### 2. 🚀 Установка и запуск проекта

npm install
npm run dev
После запуска открой <http://localhost:5173> в браузере.

### 3. 📜 Доступные скрипты

🚀 **Запуск приложения в режиме разработки**

npm run dev
Запускает Vite в режиме разработки. Доступен по умолчанию на <http://localhost:5173/>.

🛠️ **Сборка проекта**

npm run build

👀 **Предпросмотр собранного проекта**

npm run preview

🔍 **Проверка кода (ESLint)**

npm run lint

🎨 **Форматирование кода (Prettier)**

npm run format

💅 **Проверка стилей (Stylelint)**

npm run lint:styles

🧪 **Запуск тестов (Jest)**

npm run test

🪛 **Подготовка Git-хуков (Husky)**

npm run prepare
